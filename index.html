Edición de aula

Cómo llega esta página a internet

  1. 01

    GitHub

    HTML, CSS y un archivo de compilación. La rama main es la fuente.

  2. 02

    Amplify

    Detecta el push, ejecuta el build y publica los archivos estáticos.

  3. 03

    URL pública

    La página queda disponible con certificado HTTPS, sin servidor propio.
